# Podcast Fetcher

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/redundans/podcast-fetcher.svg)](https://packagist.org/packages/redundans/podcast-fetcher) [![Total Downloads](https://img.shields.io/packagist/dt/redundans/podcast-fetcher.svg)](https://packagist.org/packages/redundans/podcast-fetcher)

A [Flarum](https://flarum.org) extension. A extension that create diskussions for every podcast episodes from a json-feed.&#39;

## Installation

Install with composer:

```sh
composer require redundans/podcast-fetcher:"*"
```

## Updating

```sh
composer update redundans/podcast-fetcher:"*"
php flarum migrate
php flarum cache:clear
```
